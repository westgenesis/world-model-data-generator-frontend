检查项所属环节判定口径填写方式不通过时的处理
画面清晰度环节①目标轮廓可辨、无糊化选择：符合 / 不符合记不合格原因 → 退出流转
多模态一致性环节①视频目标与点云位置对应选择：符合 / 不符合记不合格原因 → 退出流转
时间对齐环节①多路视频与点云同一帧号同步选择：符合 / 不符合记不合格原因 → 退出流转
画面异常区域环节①无穿模、无异常块、无重复帧选择 + 填写起始帧号记不合格原因 → 退出流转
物理合理性环节①目标运动不跳变、不穿越选择 + 填写目标 ID记不合格原因 → 退出流转
标签完整性环节②必填标签无缺失选择：通过 / 不通过退回重标
目标类别正确环节②与标注规范的类别一致选择 + 填写目标 ID退回重标
框贴合度环节②3D 框与目标轮廓贴合选择 + 填写偏差值（m）退回重标
