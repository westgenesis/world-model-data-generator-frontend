# 场景编辑器：实现说明

> 前置文档：`场景编辑器_OpenDRIVE与按帧编辑_技术预研.md`、`场景编辑器_技术验证报告.md`
> 页面：`/scene-editor/:sceneId`
> 代码：`src/features/scene-editor/`

## 1. 功能

| 功能 | 说明 |
| --- | --- |
| 导入 / 导出 | 支持 .xodr 和 .xosc，可多选，也可直接拖到画布上。导出时原样保留未改动的内容（未识别的节点、注释、参数） |
| 渲染 | 路网：车道、标线、路口连接道路。场景：目标物、初始位置、折线轨迹 |
| 添加目标物 | 从左侧元件库拖到画布，或单击放到视野中心。可选：轿车、SUV、货车、公交车、摩托车、自行车、行人、锥桶、护栏。开启"吸附车道"时，落点会贴到最近车道中心，朝向沿车道行驶方向 |
| 编辑属性 | 名称（引用同步更新，包括通过参数间接引用的）、类别、尺寸 / 预设、初始位置与朝向、初始速度；目录引用实体可"转为内联"定义 |
| 编辑轨迹 | 见下文"编辑轨迹"一节 |
| 时间轴 | 播放 / 暂停（实时，0.5–4 倍速）、逐帧、拖动播放头、拖动关键帧改时刻（吸附到帧） |
| XML 分屏 | 用 CodeMirror 预览并直接修改 xosc / xodr。改动是草稿，⌘S 应用；语法错误会标出行列，且不会覆盖当前文档；画布与文本互相同步 |
| 校验 | 检查：引用了不存在的实体（含参数引用）、名称重复、关键帧时刻、速度过快、离开路面、缺少 LogicFile、条件触发轨迹的提示 |
| 其他 | 撤销 / 重做（100 步）、本地草稿（localStorage）、离开页面前提醒、暗色模式 |

**编辑轨迹的方式**：
- **"绘制轨迹"工具**：在画布上逐点单击。新点的时刻 = 上一点时刻 + 距离 / 绘制速度。
- **拖动关键帧手柄**：直接在画布上拖动轨迹上的点。
- **自动记帧**：把播放头移到某一时刻，再拖动目标物，就会在该时刻新增或更新关键帧。
- **关键帧表**：直接编辑时刻 / X / Y；与上一段速度相差超过 15% 时会高亮。

**快捷键**：

| 按键 | 作用 |
| --- | --- |
| V / H / D | 选择 / 平移 / 绘制轨迹 |
| F | 适应视图 |
| 空格 | 播放 / 暂停 |
| ← → | 逐帧 |
| Delete | 删除选中的关键帧或目标物 |
| Esc | 退出工具 / 取消选中 |
| ⌘Z / ⌘⇧Z | 撤销 / 重做 |
| ⌘S | 保存草稿；在 XML 编辑器内为应用修改 |

**本期不做**：路网图形化编辑（只能改 XML 文本）、条件触发动作的回放、目录文件加载、后端持久化。

## 2. 架构

**XML DOM 是唯一数据源**：

- Store（`stores/scene-editor-store.ts`）只保存两份 `XmlSource`。路网模型、车道网格、场景模型、位姿和关键帧都由它们派生（`hooks/use-scene-model.ts`）。文档对象不可变，派生结果按引用缓存，因此路网不变时不会重新采样。
- 界面编辑都调用纯函数 `(doc, …) => newDoc`（`core/openscenario/edit*.ts`）：先克隆，只改相关节点，新插入的节点按文件原有缩进排版（`core/dom.ts`）。撤销 / 重做就是文档快照栈。
- 修改 XML 文本时，解析新文本并替换文档；解析失败抛错，不改变状态。
- 拖拽中的临时位置只在画布组件里，松手才提交，避免每帧克隆和解析。

**关键帧轨迹的写法**：

- 编辑器为每个实体在 `Story name="WMDG_EditorStory"` 下生成：
  - `ManeuverGroup` → `Event`，由 `SimulationTimeCondition ≥ 0` 触发
  - `FollowTrajectoryAction`，其中轨迹为 `Polyline`，顶点写 `WorldPosition`，朝向按轨迹方向计算
  - `Timing domainAbsoluteRelative="absolute"`、`followingMode="position"`
- OpenSCENARIO 1.1 及以上用 `TrajectoryRef`，1.0 直接写 `Trajectory`。
- 导入场景里只属于某个实体的折线轨迹，会被原地改写，不另建 Story。
- 首个关键帧即初始位置。首帧位置不变时，保留原有的 `LanePosition` 等写法。

**目录结构**：

```
core/                 与 React 无关的纯 TS
  xml.ts dom.ts       解析 / 序列化 / 按缩进插入节点
  opendrive/          解析、几何（5 种线形）、车道采样、投影（吸附车道 / 路面判断）
  openscenario/       解析、参数表达式、位置解析、运动（插值 / 段速度）、编辑函数
  validate.ts         校验
  __verify__/         与 esmini 交叉验证（需 ESMINI_HOME）
stores/               Zustand：文档 + 历史 + 界面状态
hooks/                派生模型、编辑动作、导入导出与草稿、快捷键、播放头位姿
components/           元件库、画布（Konva）、时间轴、属性面板、XML 分屏（懒加载）
```

## 4. 已知限制与后续

- 编辑器生成的轨迹从仿真开始就按绝对时间执行。如果实体还有导入场景中的其他动作（变道、跟车等），仿真时可能互相覆盖，校验面板会提示。
- `RoutePosition`、Clothoid / Nurbs 轨迹只能保留，不能显示和编辑。
- 草稿存在浏览器本地，大地图可能超出 localStorage 容量（保存失败时会提示）。后续接入场景资源接口。
- 路网图形化编辑、按车道坐标编辑关键帧（`lane-follow` 插值）留待后续。
